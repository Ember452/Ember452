I'm **ZhenHao Jiao** (`Ember452`), a builder focused on **agent harnesses** — the layer that turns an LLM into a reliable, inspectable worker.

## 🧭 Principles

- **Local-first** — your data and agent state stay yours.
- **Inspectable** — every step should be traceable.
- **Small kernel, pluggable policy** — keep the core readable.
- **Durable** — sessions should survive restarts.
